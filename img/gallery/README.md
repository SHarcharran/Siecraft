# Gallery photos

1. Drop JPG photos in this folder (about 1600px wide, under 400 KB each).
2. Add each one to `gallery.json`:

```json
[
  { "src": "/img/gallery/walnut-family-sign.jpg", "caption": "Walnut family name sign" },
  { "src": "/img/gallery/memorial-plaque.jpg", "caption": "Cedar memorial plaque" }
]
```

The Gallery tab stays hidden while this list is empty.
