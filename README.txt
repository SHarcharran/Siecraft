HOW TO PUBLISH
--------------
OPTION 1 — Netlify (Free, 30 seconds):
  1. Go to netlify.com/drop
  2. Drag the index.html file onto the page
  3. Your site is live instantly with a free netlify.app URL
  4. Then add your custom domain SieCraft.com in Netlify settings

OPTION 2 — Your Existing Host:
  1. Log into your web hosting control panel
  2. Open File Manager → public_html folder
  3. Upload index.html
  4. Done — visit SieCraft.com to confirm

OPTION 3 — Square Online (Current Site):
  Add the website as a custom HTML page in your Square Online dashboard.
  Note: Square may limit full HTML embedding. Netlify is recommended for full control.
